# Consolium public portal demo

Standalone copy of the Consolium public web design. Results, standings and schedule use synthetic sample data from `mock-data.json`; this is not live festival information. The homepage uses the existing prebuilt assets.

Run `node server.cjs` and open http://localhost:8080/consoulium. Static hosts must map `/` and `/consoulium` to `consoulium.html` as in `_redirects`.
